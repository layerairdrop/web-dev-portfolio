Kodenya Publik. Jadi Kamu Bayar Untuk Apa?

Semua bot di halaman ini punya repository publik. Bisa kamu clone gratis hari ini, tanpa bertanya. Itu disengaja: di pasar yang penuh script abu-abu, satu-satunya cara membuktikan bot tidak menyentuh wallet kamu adalah membiarkan kodenya dibaca siapa saja.

01

Lisensi Resmi

Lisensi tercatat atas namamu, terkunci ke 1 device (HWID). Bukan file anonim yang berpindah tangan tanpa jejak.

02

Update Mengikuti Project

Project crypto ganti API, tombol, dan alur tiap beberapa minggu. Versi berlisensi dapat penyesuaian, bukan kamu patch sendiri tiap kali bot berhenti.

03

Support Prioritas

Mentok di config, proxy, atau captcha? Ada jalur tanya ke pembuatnya. Yang clone dari GitHub tidak dapat bagian ini.

04

Versi Sudah Dikonfigurasi

Sudah dites dan disesuaikan dengan alur project terkini. Yang kamu hemat: waktu ngoprek, bukan uang.

Clone gratis tetap boleh. Kalau kamu bisa baca kodenya dan paham cara patch sendiri, silakan pakai tanpa bayar. Kami cuma menyediakan jalan pintas buat yang tidak punya waktu.

FAQ

Kodenya ada di GitHub gratis. Kenapa harus bayar?
Karena yang kamu beli bukan kode. Kamu beli lisensi resmi yang tercatat, update saat project berubah API atau alur, support langsung ke pembuatnya, dan versi yang sudah dikonfigurasi siap jalan. Clone-an dari GitHub tidak dapat satu pun dari itu.
Apakah bot ini aman? Bisa mencuri wallet?
Kodenya publik dan bisa kamu baca sendiri sebelum menjalankan apa pun. Bot memakai wallet kamu sendiri, berjalan lokal di komputer kamu, dan tidak mengirim private key ke mana pun. Ini alasan kami tidak menyembunyikan repository.
Berapa lama lisensi berlaku?
Lisensi terkunci ke 1 device (HWID) dan tidak punya masa aktif untuk versi yang kamu beli. Update gratis selama versi itu masih dipakai project. Kalau mau akses semua bot plus update berkelanjutan, pakai VIP Rp 300.000/bulan.
Ada garansi?
Garansi kami mencakup konfigurasi dan troubleshooting hingga script berhasil berjalan di 1 device, termasuk bantuan remote untuk masalah environment. Kami tidak menyediakan refund jika kegagalan disebabkan oleh perubahan API, downtime, atau perubahan aturan mendadak dari pihak ketiga (proyek crypto). Sebagai gantinya, kami berkomitmen memberikan update script secara berkala mengikuti perubahan proyek, serta akses ke dokumentasi lengkap dan support prioritas.
Apakah butuh proxy?
Untuk multi-wallet, sangat disarankan. Untuk 1-3 wallet, tidak wajib. Yang kami rekomendasikan proxy residential, bukan datacenter.
Bot support chain apa saja?
Tergantung bot. Kebanyakan EVM (Ethereum, Base, BSC, Polygon, Arbitrum). Beberapa support Solana, Cosmos, dan chain lain. Kolom chain di tabel atas menunjukkan masing-masing.
Kalau project-nya tutup atau berhenti?
Bot mengikuti project, bukan sebaliknya. Kalau project berhenti sebelum TGE atau mengubah aturan secara drastis, bot terkait ditandai di channel. Untuk kasus ini tidak ada refund, tapi kamu tetap dapat akses ke bot lain sesuai paket yang dipakai.
